    LLM MLA MoE 线性注意力

    Kimi K3 架构分析

    [!INFO] 源文章 源文章：科学空间《简单谈谈K3的MoE和Attention》（苏剑林，2026-08-04）。一句话：K3 = KDA + MLA + Stable LatentMoE + AttnRes；优化器仍是 Moonlight 版 Muon（Attention 权重改 Per-Head 优化，动机是正确性而非效果——"每个 Head 本就独立，不应耦合"）。主旋律：效果、效率、稳定性的协调。AttnRes 见《Attention Residuals 回忆录》，KDA 见《Kimi Linear》技术报告。

    1. SiLU 与 SwiGLU 的病根

    1.1 SiLU 本体

    \(SiLU(x) = x \cdot \sigma(x)\)（aka Swish）。三个关键特征：正区 ≈ 恒等（线性增长、无上界）；负区小凹坑（x≈-1.28 处最低 ≈ -0.278）后归零；自门控（σ(x) 是 0\~1 软开关）。

    1.2 在 SwiGLU 里的位置

    \(SwiGLU(x) = W_3\big(\mathrm{SiLU}(W_1 x) \odot W_2 x\big)\)：门控分支（放行多少）× 线性分支（内容本体）。实证稳赢 GELU/ReLU FFN，是 Llama/Qwen/K2 全系标配。

    1.3 病根：正区无上界 × 乘性结构 = O(‖x‖⁴)

    1. 门控爆：W1 某一行 w 与输入 x 同向（align）时 |w·x| 可以非常大，而 SiLU 对大正值 ≈ 恒等，一点不拦；
    2. 线性分支同时爆：W2·x 在同一通道也大；
    3. 相乘：两个 O(‖x‖²) 量级的数相乘 → O(‖x‖⁴) 级异常值。

    这就是 LLM 里大名鼎鼎的 activation outlier（LLM.int8() / SmoothQuant 一族量化工作收拾的就是它），SwiGLU 的乘性结构是放大器；BF16/FP8 低精度训练下轻则毁统计量、重则 inf。关键认识：问题不在 SiLU 本身，在于"正区无限幅" + "两分支相乘"的组合。

    延伸：凡是丢掉 softmax 这把"数值安全锁"的注意力变体（线性注意力等），数值范围都要靠激活函数/限幅自修闸门——K3 的 softcap 与这类硬闸（ReLU6 式截断）是同一问题的两种解法，softcap 平滑且同样界限下效果更好。

    2. LatentMoE：原理与好处

    2.1 普通 MoE 的两本账

    每个 expert 是 FFN：d → h → d（K2/K3 的 d=7168），n 个专家选 k 个：

    每 token 计算 总参数（知识容量）
    普通 MoE k × 2dh n × 2dh
    LatentMoE 2k × (d·h) + 共享投影 ≈ 持平 2n × dh = n × 2dh（持平）

    2.2 结构

    普通 MoE:    d ──→ D ──→ d            （n 选 k，专家全宽）
LatentMoE:   d ──→ d/2 ──→ D ──→ d/2 ──→ d
              降维(共享)   2n 选 2k     升维(共享）
                        （专家在半宽空间干活）

    降/升维投影为所有 routed expert 共享，每个专家只在 d/2 宽空间里做 d/2→D→d/2。核心：2n 个半宽专家 ≈ n 个全宽专家的总参数量。

    2.3 好处

    • 知识切分更细：448 个"全科大夫" → 896 个"专科大夫"；
    • 组合空间指数变大：C(448,8) → C(896,16)——容量没变，表达自由度大增；
    • 即论文标题《Toward Optimal Accuracy per FLOP and Parameter》：同成本下效果略好。

    2.4 K3 落地

    448选8 → 896 选 16（稀疏度不变 1/56）；latent 宽度 3584 = 7168/2；2 个 shared expert 保持全宽——通用计算不被低维瓶颈卡住："通用的事走大路，专精的事钻小路"。

    2.5 代价：四个矩阵连乘 → "Stable" 三件套

    d ──W_down──→ d/2 ──W1──→ D ──W3──→ d/2 ──W_up──→ d
     ①矩阵      ②矩阵(门控)  ③矩阵     ④矩阵

    裸线性链 + 乘性门控，数值极不稳定，异常值顺四个矩阵一路放大。三件保险全是给这条链上的：

    保险 位置 作用
    SiTU-GLU 专家内部 softcap 封顶 O(‖x‖⁴) 异常值（β1=4 门控、β2=25 线性；softcap 优于 Hard Clip）
    RMS Norm 升维前（W_up 之前） 消融显示这个位置最本质（最小改动原则只留这一个）；彩蛋：对 valid loss 影响不大，但某些 benchmark 不加会稳定变差——猜测平衡了 Routed/Shared 比例，加了就不用 Scaling Factor
    QB 路由侧 896 专家的负载均衡（见第 3 节）

    3. MoE 负载均衡：从 aux loss 到 QB

    3.1 传统前向流程（六步）

    ① 打分   s_i = w_i·x                    （router 给 896 专家各打一分）
② 选择   Top-k over (s_i + b_i)         （b_i 是均衡偏置）
③ 门控   p_i = σ(s_i) 或 softmax        ← 用【不带 b】的原分数
④ 分发   token 发给选中专家所在卡        （EP 下 all-to-all 通信）
⑤ 计算   y_i = E_i(x)
⑥ 合并   y = Σ p_i·y_i (+ shared expert 输出）

    关键细节：bias 只参与"选谁"（②），不参与"给多少权重"（③）——均衡器只改路由决策，不污染输出语义。

    3.2 负载不均衡问题

    Router 训练会富者愈富：早期被多选 → 梯度多 → 更强 → 更被多选。后果：容量浪费 + EP 下最忙的卡是短板，全集群等它。

    3.3 三代做法对比

    做法 机制 干扰主任务 超参 大规模（896）表现
    aux loss（Switch 时代） loss 里加均衡项（f_i·P_i） 有（α 调和） α 一般，软均衡
    Loss-Free（K2/DSv3） bias 按 sign 试错：b ← b − u·sign(f̄−1/n) 无 步长 u 不稳：binary 反馈太粗糙，逐比特挪动会震荡
    QB（K3） bias = 余量分布的 k/n 分位数（闭式） 无 无 稳

    3.4 QB 推导链

    均衡的数学目标：每专家被选概率 = k/n（896 选 16 → 1/56 ≈ 1.8%）。入选门槛 = top-k 卡的线 = 第 k+1 大的分数 \(\tau_t\)。专家 i 入选 ⇔：

    \(s_i + b_i > \tau_t \;\Leftrightarrow\; d_t := \tau_t - s_i < b_i\)　（\(d_t\) = "余量"：离入选还差多少）

    于是被选概率 = P(d_t < b_i)，要它等于 k/n，bias 直接取余量分布的 k/n 分位数：

    \(b_i = \mathrm{Quantile}_{k/n}\big(\{d_t\}\big)\)　——不迭代、不试错、无超参，一步到位。SignSGD 式更新本质上是对这个闭式解的蹩脚随机逼近（每次只挪一个符号位），专家多了必然震荡；QB 是直接把答案算出来。

    3.5 工程落地：直方图近似（利用分布可加性）

    分位数是非线性运算：不能各卡算各的再平均（局部分位数+全局平均在规模大后失真）；朴素 all-gather 全体分数通信爆炸。K3 的解法：

    ① 把余量 d_t 压缩到 [0,1]
② 本地建直方图：1000 个 bin 的计数向量      ← 非线性消失，只剩计数
③ 跨机器 / 跨梯度累积：直方图直接相加        ← 分布的可加性！
④ 从全局直方图 CDF 读出 k/n 分位数 → b_i
    • 通信量从"全体分数"降到"每专家 1000 个计数"（896×1000 ≈ 3.5MB，几乎免费）；
    • bin 数消融：10000 bin 对比 1000 bin 无额外收益 → 1000 够用。

    4. KDA 的衰减机制

    https://zhuanlan.zhihu.com/p/2064688483621397412

    4.1 状态更新：衰减 + 擦除 + 写入

    \[S_t = \mathrm{diag}(\alpha_t)\, S_{t-1}\,(I - \beta_t k_t k_t^\top) + \beta_t k_t v_t^\top\]
    • \(\mathrm{diag}(\alpha_t)\)：衰减（遗忘）——本文主角；
    • \((I - \beta_t k_t k_t^\top)\)：delta rule 擦除——按当前 key 方向清掉旧响应（数学上 = 对"当前 key 的回读误差"做一步梯度下降）；
    • \(+ \beta_t k_t v_t^\top\)：写入新值。

    4.2 擦除是怎么完成的：方向性对消

    常见疑惑：状态 \(S = \sum_j k_j v_j^\top\) 只是外积的累加和，没有任何条目结构，怎么"擦掉前面写入的"？答案：沿某方向的旧响应是总和的线性投影，可以直接从总和里读出来、再减掉——不需要定位到"哪一笔"：

    \(k^\top S = \sum_j (k^\top k_j)\, v_j^\top\)　（所有旧记忆按与 k 的相似度加权的总和，一次矩阵乘）

    数字例子（d_k=2，key 已归一化）

    ① 正交方向互不干扰：

    t1: k₁=(1,0), v₁=5  → S = [5, 0]ᵀ
t2: k₂=(0,1), v₂=3  → S = [5, 3]ᵀ
读 q=(1,0) 得 5，读 q=(0,1) 得 3 —— k₁ᵀk₂=0，各方向互不掺和

    ② 同方向覆写：擦 vs 不擦：

    t3: k₃=(1,0)（与 t1 同方向），v₃=7

不擦（纯累加）：S = [5,3]ᵀ + (1,0)·7 = [12, 3]ᵀ → 读出 12 = 5+7 混叠 ✗

delta rule：r = k₃ᵀS = 5        （查旧账：这个方向记的是 5）
            e = 7 − 5 = 2       （差额）
            S += k₃·2 → [7, 3]ᵀ → 读出恰好 7 ✓
            旧的 5 被代数上精确抵消

    ③ 部分相似 = 按比例擦：若 k₃=(cos45°, sin45°)，则 r = 5×0.71 + 3×0.71 = 5.66——两个方向的旧值各被擦掉一部分。不完全正交的记忆会互相"渗透"，这是固定状态记忆的固有串扰。

    要点

    • 擦除不是"找到并删除"，是一次方向性对消：从求和里减去该方向上的累计响应 \(k_t (k_t^\top S_{t-1})^\top\)；
    • \(k k^\top\) 是该方向的 rank-1 投影：正交方向贡献 ≈0 不受影响；L2Norm 保证 \(k^\top k = 1\) 时 β=1 严格清零（完全同向 = 最新写入独占该方向）；
    • 成本只有 O(d_k·d_v) 一次乘加，却达到"覆写"语义——这就是 delta rule（Widrow-Hoff LMS）名字的由来：对"当前 key 的回读误差"做一步梯度下降。

    4.3 衰减的三个特征

    1. 逐 key 通道：\(\alpha_t \in (0,1)^{d_k}\)，不是标量——记忆板每一列（每个 key 方向）有自己的遗忘速度，即"不同通道的记忆寿命不同"。GDN 只有标量/粗粒度衰减，KDA 把它细化到通道粒度。
    2. 数据依赖：\(\alpha_t\) 由当前输入实时生成——模型学会"这段该忘、那段该记"，没有把时间尺度焊死在结构里。

    3. 带下界的参数化（K3 的数值关键）：

    4. GDN / Kimi Linear 原版：\(g_t = -\mathrm{softplus}(\cdot)\)，log-decay 可以趋于 −∞；

    配套件：ShortConv（块内短卷积给局部顺序感）+ q/k L2Norm（控制长度）+ 输出门控（读出时按输入调制通道）。

    4.4 一句话定位

    固定状态 = 可结合的线性 attention 的必然结果；压缩记忆必然发生写入碰撞；delta rule 把"覆盖规则"写成最小化回读误差；逐通道衰减让不同记忆有了各自的保质期。KDA 的角色：承担大部分高频、低成本的状态更新，把精确全局检索让给少数 MLA 层（69:24，≈3:1，block 内 3 KDA + 1 Gated MLA，最后一层为 MLA）。

    5. MLA（Multi-head Latent Attention）

    MLA 是 DeepSeek-V2 提出的注意力变体，目标：把 KV Cache 压小一个量级，同时不掉效果。K3 的 93 层里 24 层用它（Gated MLA），其余 69 层是 KDA（无 cache，固定状态）。

    5.1 要解决的问题：KV Cache 太胖

    softmax attention 每个历史 token 都要存 K、V。以 96 头 × 每头 128 维计：cache = 2×96×128 = 24576 个数 / token / 层，1M context 下是天文数字。MQA/GQA 用"共享头"砍 cache，但表达力受损。

    5.2 结构：存压缩包，用时解压

    写入：x_t ──W_down(共享)──→ c_t ∈ R^512     ← KV 压成一个 latent，【只存它】
读取：c_t ──W_UK──→ 96 个头的 K（每头 192 维）
      c_t ──W_UV──→ 96 个头的 V（每头 128 维）

    cache 对比：MHA 24576 vs MLA 512+64=576（约 1/43；64 是 RoPE 解耦位）。

    5.3 关键机制：解码时的"吸收"（absorb）

    上投影 W_UK/W_UV 是共享线性层，可挪到 query 侧"吸收"掉：

    \[\mathrm{score}(q_i, k_j) = q_i^\top W_{UK} c_j = (W_{UK}^\top q_i)^\top c_j\]

    右边括号里对每个 query 只算一次。于是解码时根本不用解压——96 个 query 直接对着 512 维共享 latent 打分，等价于 head_dim=512+ 的 MQA（所有头共享一个超大 K/V）。注意 RoPE 与低秩压缩不兼容（位置旋转矩阵夹在中间破坏结合律、无法被吸收），所以单独走一个小的解耦分量（64 维、MQA 式全头共享）——这就是"拼接 64 维"的由来。

    5.4 为什么压缩了效果不掉

    《MLA 好在哪里》系列的实验结论：效果的关键是"无形的 head_dims 变大"——latent 让每头的有效视野是 512 维共享空间；给定 cache 预算，理论最优是"head_dims = cache 大小、K=V 共享的 MQA"。MLA 两头占：训练时像 MHA（好训、效果好），解码时像大 head_dims MQA（cache 小、质量保住）。

    5.5 代价与四条件取舍

    • MLA 解码已是 head_dims=512+ 的 MQA，算力提前耗光 → 配 MTP（推测解码，计算换速度）吃亏；
    • 往小改（GQA8 128+128）：效果打不过 MLA；就算打平，cache 也是 MLA 三倍多；
    • 往大改（MFA 256+256，本质 MQA）：效果追平、cache 不多，但训练成本涨（Scaling Law 吃亏）、Prefill 也变贵（Agent/Coding 每轮 prefill 不短）。

    比 MLA 更好的设计必须同时满足：①效果 ≥ MLA　②训练+Prefill 成本 ≤ MLA　③KV Cache < MLA　④Decoding 计算 < MLA——目前没有设计能同时满足，必须取舍。K3 里 KDA 承担大部分层的序列混合，MLA 只留 24 层，其成本问题被"稀释"，所以权衡后仍选 MLA。

    5.6 插曲：DSV4 没有抛弃 MLA

    DSV4 看似另起炉灶，实际是把 MLA 的解码形态（head_dims=512、K=V 的 MQA）直接当成了训练形态——按理论最优解走到底；代价靠 Sparse（省计算）+ Compress（压 cache）找补。评价："不是抛弃和重造，是传承和升级到另一个极致"。但 "Linear+Full" 路线 vs "Sparse" 路线谁走更远，尚无定论。

    5.7 K3 的两个自家改动

    • Gated MLA：输出加 data-dependent 门控（与 KDA 的输出门呼应——attention 读出再被当前输入调制一遍）；
    • NoPE：去掉 RoPE——因为 KDA 隐含提供了"广义 RoPE"（见第 6 节讨论）；
    • 工程细节：保留"拼接 64 维 RoPE 槽位"的旧结构而不直接投影 576 维 latent——兼容现有 MLA 基建、计算更省无收益、且 K3 新变量已经够多（"饭要一口一口吃"）。
