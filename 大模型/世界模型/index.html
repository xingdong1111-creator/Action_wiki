    世界模型 JEPA 视频生成 Cosmos Genie

    世界模型：生成式 vs JEPA

    前面聊 JEPA 时，说的是“在隐空间预测，不生成像素”；UniPi / Genie / Cosmos 这一串正好相反：真的把未来像素/视频画出来。两条路线都在回答“模型如何理解世界”，但下注方式不同：

    • JEPA 路线：隐空间预测，不画像素，预测式。
    • 生成式路线：生成未来视频/可交互世界，生成式；“会画未来 = 懂世界 = 能决策”。

    生成式路线的赌注是：如果模型能生成物理上合理的未来视频，它内部一定隐含了世界动力学，就能拿来规划/控制。

    1. 生成式路线

    1.1 UniPi（2023，MIT + Google）：策略即视频生成

    论文：Learning Universal Policies via Text-Guided Video Generation。

    核心思想：把“顺序决策”重新表述为“文本条件的视频生成”问题。

    文本指令 "把红块放进碗里" + 当前观测帧
        │
        ▼
文本条件视频扩散模型（Planner）
        │
        ▼
生成一段“未来该怎么做”的视频（一帧帧画出来）
        │
        ▼
逆动力学模型（Inverse Dynamics）
        │
        ▼
从相邻帧反推出动作 a_t → 执行

    两个关键部件：

    1. 视频扩散当 planner：生成“任务应该长什么样”的未来帧序列。
    2. 逆动力学模型提取动作：从生成视频的相邻帧之间反解出机器人动作。

    为什么叫“universal”：所有环境/任务都被统一表示成“图像空间里的视频”，不同状态/动作空间被抹平到同一个像素接口，靠语言泛化到新目标、新任务。

    历史地位：第一个明确提出“video generation = policy”的工作，是整条生成式路线的思想源头。但慢、依赖逆动力学、生成质量受限。

    1.2 Genie（DeepMind，2024 → Genie 3，2025）：可交互、可玩的世界

    论文：Genie: Generative Interactive Environments。

    UniPi 生成的是“一段固定视频”；Genie 的突破是生成一个你能实时操控的世界。

    Genie 1 的三大创新：

    海量无标注互联网视频（无动作标签）
        │
        ├─ ① Latent Action Model（潜动作模型）
        │     从相邻帧【无监督地】学出“潜在动作”
        │
        ├─ ② Video Tokenizer（把帧压成 token）
        │
        └─ ③ Dynamics Model（时空 Transformer）
              给定过去帧 + 潜动作 → 预测下一帧
        ▼
一个可以“按潜动作逐帧推进”的可交互环境

    最惊艳的点：从纯无标注视频里自监督学出“动作”这个概念（latent actions），不需要任何动作标注。这解决了机器人/生成世界模型最大的痛点——动作标注太贵。

    Genie 3（2025.8）：

    • 通用世界模型：一句文本 → 生成照片级、可实时导航的交互环境。
    • 实时、长时程一致性大幅提升，是“生成式可交互世界”目前的天花板级 demo。
    • 用途：给 agent 提供无限的、可交互的训练/评估环境（类似给具身智能造“无限游戏世界”）。

    Genie 的定位：不是直接做机器人策略，而是造“可交互的世界模拟器”——既可当 agent 的训练场，也印证了“生成式世界模型”的可行性。

    1.3 Cosmos 1（NVIDIA，2025.1）：把世界模型做成工业平台

    论文：Cosmos World Foundation Model Platform for Physical AI（arXiv 2501.03575）。

    UniPi/Genie 是研究原型，Cosmos 是 NVIDIA 把它工程化、平台化、面向真实产业（机器人 + 自动驾驶）。

    三件套模型（都可 post-train 定制）：

    模型 作用
    Cosmos-Predict 预测未来世界状态（生成视频）——核心世界模型，支持 Text2World / Image2World / Video2World
    Cosmos-Transfer 跨域/跨模态迁移（如仿真 ↔ 真实、加不同条件控制生成）——主要用来造合成训练数据
    Cosmos-Reason 一个物理 AI 推理 VLM，懂物理常识，还兼做 Predict 的文本编码器

    再加上：Tokenizer（把视频高效压成 token）+ 数据 curation 管线 + guardrails（安全护栏）。

    Cosmos 的真正商业用途：大规模生成合成数据——为自动驾驶、机器人生成海量物理上合理的场景视频，喂给下游模型训练。这是它区别于纯研究的落地点。

    1.4 Cosmos Policy：世界模型“长出”策略

    在 Cosmos-Predict2.5 里有一个具体模型：Cosmos-Predict2.5-2B/robot/policy。

    • 在 Libero、RoboCasa（机器人操作 benchmark）上 post-train；
    • 输入：action + image；
    • 定位（NVIDIA 官方原话）：“policy model 把预学到的动作适配到具体任务、领域和行为上”。

    它的意义：把“生成式世界模型”从“预测未来/造数据”进一步推到直接输出机器人策略。也就是完成了 UniPi 的初心——世界模型不只是模拟器，它本身可以微调成策略。

    对应“世界模型当预训练骨干 → 微调出策略”的混合路线，这是它在生成式路线上的落地。

    1.5 Cosmos 3（2025 底 / 2026）：一个模型统一所有能力

    Cosmos 1/2.5 还是三个专门模型分工（predict / transfer / reason）。Cosmos 3 的核心变化：用一个统一架构，一个模型全干。

    官方原话拆解：

    A single Cosmos 3 model can reason, predict future world states, transfer across domains and modalities, and generate actions and policies for embodied agents — within one unified architecture.

    即一个模型同时具备：

    1. 推理（reason）
    2. 预测未来世界状态（predict）
    3. 跨域跨模态迁移（transfer）
    4. 为具身智能体生成动作与策略（policy）

    趋势判断：这是“世界模型”走向统一基础模型（Unified WFM）的信号——把理解、预测、迁移、决策揉进一个大模型，对标 V-JEPA 2 的“理解 + 预测 + 规划三合一”，但走的是生成式而非预测式路线。

    1.6 生成式路线演进链

    UniPi (2023) ── “视频生成 = 策略”的思想开山
   │            （文本 → 生成未来视频 → 逆动力学出动作）
   ▼
Genie (2024→3, 2025) ── 可交互世界；无监督学出潜动作；造可玩世界模拟器
   │
   ▼
Cosmos 1 (2025.1) ── 工业平台化：Predict / Transfer / Reason 三件套 + 造合成数据
   │
   ├── Cosmos Policy ── 世界模型 post-train 成机器人策略（action + image）
   ▼
Cosmos 3 (2025 末) ── 统一架构：reason + predict + transfer + policy 一个模型全包

    2. JEPA 路线

    JEPA 的训练范式可以概括为两步：① 只训 encoder——图片/视频挖孔，做掩码表征预测，学基础认知；② 加动作——给图片 + 动作，预测未来视频的隐空间表征。全程没有 decoder，回不到像素空间。

    2.1 JEPA（2022）：理论框架

    提出时间：2022 年 6 月，LeCun 在立场论文 A Path Towards Autonomous Machine Intelligence 中正式提出。

    核心思想：放弃像素/token 级的逐点重建，改为在抽象的潜在表征空间中预测未来或缺失的信息。

    架构组成（非对称三组件）：

    • Context Encoder：提取可见输入的特征，梯度可回传。
    • Target Encoder：提供目标表征，参数通过 EMA 从 Context Encoder 更新，梯度停止。
    • Predictor：基于上下文表征预测目标表征。

    训练目标：最小化预测表征与真实目标表征之间的距离（L1/L2 损失），无需解码器还原原始数据。这套非对称设计（EMA target encoder + stop-grad + predictor）也是防止表征坍塌的关键。

    为什么重要：LeCun 认为自回归 LLM 缺乏对物理世界的理解，JEPA 是他构想的 AGI 技术路径的核心——让机器通过被动观察学习世界的“内部模拟”，而非单纯的语言预测。

    2.2 V-JEPA（2024）：视频领域落地

    论文：V-JEPA（arXiv 2404.08471）。

    核心升级：将 JEPA 从静态图像扩展到动态视频序列，采用 3D tubelet 掩码策略 + 时空 ViT 架构，在时空维度学习动作和场景的抽象规律。

    关键设计：

    • 3D 多块掩码：在时空维度上随机遮蔽部分 patch token，迫使模型学习长程时空依赖。
    • L1 回归损失：在表征空间做回归预测，而非像素重建。
    • 渐进式训练：从 16 帧短视频逐步扩展到 64 帧长视频，让模型学会长期一致性。

    能力边界：仅支持视频分类、行为预测等视觉理解任务，还没有动作条件和规划能力。

    2.3 V-JEPA 2（2025）：从“看懂”到“操控”的质变

    论文：V-JEPA 2（arXiv 2506.09985）。

    四维升级（相比 V-JEPA）：

    维度 V-JEPA V-JEPA 2
    数据量 200 万样本 2200 万样本（VideoMix22M），超 100 万小时视频
    模型规模 6 亿参数（ViT-H） 10 亿参数（ViT-g）
    训练迭代 9 万次 25.2 万次
    位置编码 绝对位置编码 3D-RoPE 旋转位置编码

    两阶段训练架构：

    1. 预训练阶段：用百万小时互联网视频学习通用视觉表征（编码器可训练）。
    2. 动作条件化微调（V-JEPA 2-AC）：冻结预训练编码器，新增动作条件预测器，仅用 62 小时机器人交互数据学习“动作 → 视觉状态变化”的因果映射。

    核心突破：首次实现零样本机器人规划。配合 MPC（模型预测控制），在从未见过的环境中，仅凭一张目标图片就能规划出抓取、放置等操作序列，成功率 65%–80%。

    性能数据：LIBERO 视频预测 64 帧延迟仅 0.619 秒，运行速度比 NVIDIA Cosmos 快 30 倍。

    2.4 DINO-WM（2024 / ICML 2025）：借力预训练特征

    论文：DINO-WM（arXiv 2411.04983）。

    核心思路：不从头训练视觉编码器，而是直接复用冻结的 DINOv2 预训练空间 patch 特征作为观测模型，在潜在空间中预测未来的 DINO 特征。

    架构：

    • 观测模型：冻结的 DINOv2，将 RGB 图像编码为 patch 嵌入 z_t ∈ R^(N×E)。
    • 转移模型：ViT 架构 + 因果注意力，接收历史潜状态 + 动作，自回归预测下一帧潜状态。
    • 解码器：可选，训练和推理都不需要。

    为什么用 DINOv2 的 patch 特征而不是 CLS token：实验表明，patch 特征在所有任务上始终优于全局特征（DINO CLS、R3M、ResNet），尤其在空间推理任务（wall、reach）上成功率超过 0.90，而 ResNet 低于 0.20。

    能力：在六个环境（Maze、Wall、PushT、Reach、Rope、Granular）中实现零样本行为规划，无需专家演示、奖励建模或预学习逆模型，成功率比先前 SOTA 平均提升 45%。

    2.5 JEPA 路线演进链

    JEPA（2022）          ← 理论框架：在表征空间预测，而非像素重建
  │
  ├── I-JEPA（2023）  ← 图像领域首次落地
  │
  ├── V-JEPA（2024）  ← 扩展到视频，学习时空动态
  │     │
  │     └── V-JEPA 2（2025）← 两阶段训练 + 动作条件化，实现零样本规划
  │
  └── DINO-WM（2024） ← 另一条路径：直接借用 DINOv2 预训练特征做世界模型

    V-JEPA 2 vs DINO-WM 的核心差异：

    维度 V-JEPA 2 DINO-WM
    视觉编码器 自己从头训练（ViT-g，10 亿参数） 直接复用冻结的 DINOv2
    训练数据 百万小时互联网视频 + 62 小时机器人数据 离线收集的轨迹数据
    训练成本 高（25.2 万次迭代） 低（编码器冻结，只训转移模型）
    通用性 更强（端到端学习，表征更适配任务） 依赖 DINOv2 的特征质量
    定位 “自己练出大脑” “借别人的大脑用”

    3. 两条路线的对比

    维度 JEPA 系列（V-JEPA 2 / DINO-WM） 生成式系列（UniPi / Genie / Cosmos）
    预测什么 隐空间表征（不画像素） 真实像素/视频
    哲学 只预测“决策必需的抽象状态” “能画出未来 = 懂世界”
    算力 轻，适合实时控制 重，生成慢
    优点 高效、抗无关细节干扰、适合规划 可视化、可交互、能造数据、可迁移
    缺点 不可视、目标图依赖 生成慢、可能“画得漂亮但物理错”、误差随帧累积
    LeCun 态度 力挺（这是他的主张） 公开批评（认为像素生成浪费算力在不可预测细节）
    代表落地 机器人 zero-shot 规划 自动驾驶/机器人合成数据、可交互世界

    这正是当前世界模型的核心分歧：

    • LeCun 阵营（JEPA）：预测抽象表征就够了，画像素是浪费。
    • 生成式阵营（Sora / Genie / Cosmos）：像素级生成虽贵，但能可视化、可交互、能造数据、能迁移，工业价值大。

    现实结论：

    • 要实时机器人控制 → 偏 JEPA/预测式 + 微调策略（轻、快）。
    • 要造训练数据、仿真、可交互世界、跨域迁移 → 生成式（Cosmos 的主战场就是这个）。
    • 两条路线正在合流：Cosmos 3 和 V-JEPA 2 都在做“理解 + 预测 + 决策统一”，只是一个走生成、一个走预测。

    4. 一句话总结

    这一串是“生成式世界模型”的进化史：UniPi 提出“视频生成即策略”，Genie 让世界“可交互 + 自监督学出动作”，Cosmos 把它工程化成面向物理 AI 的工业平台（并长出 policy 模型），Cosmos 3 则把推理/预测/迁移/决策统一进一个模型。它们与 JEPA 的根本分歧在于——到底该“生成像素级未来”还是“只预测抽象隐空间”。前者赢在可视化/造数据/迁移，后者赢在高效/实时控制，目前正殊途同归地走向“统一世界基础模型”。
